# Aleclarson Tap

## How do I install these formulae?

`brew install aleclarson/tap/<formula>`

Or `brew tap aleclarson/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "aleclarson/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
